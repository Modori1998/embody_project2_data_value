04 · 事件定义和后续调查点

避免误把机器人末端移动当作物体移动，也避免把抓取和搬运当成互斥标签。

Phase / 主阶段

transport（搬运）只有在 motion_phase 中；条件是可见物体随夹爪一起移动。一个 Segment 最终只选一个主阶段。

Event / 局部事件

object_motion 要求目标帧之间物体有可辨认位移。它不要求同段重新执行抓取，也不能由 EEF 路径长度直接推断。

Note / 文字描述

文字说物体静止，却输出 object_motion，属于字段间矛盾，可通过 QC 标记，但 QC 不能直接修改标签。

Prompt 版本实际上改了什么？

A · v0.2.1（冻结历史基线）

包含已确认冲突的句子：「长距离的连续搬运可能确实 events=[]；不要为了凑事件率而编造事件。」

B · v0.2.2（扩写实验）

用十条 Phase–Event 规则替换冲突句，并增加输出前一致性自检。恢复 2 个 Object Motion 正例，却新增 7 个误报。

C · v0.2.3（最小修复）

仅替换那一句话；强调可见物体位移应报告 object_motion，但不能由 EEF 或夹爪状态直接推断。误报降至 2，正例恢复为 0。
